# Archive: the first engine

These documents describe the first Internet Cat engine (ticks, five needs, a verb x object menu, a narrator, a
director, anxiety and impulses), which ran until November 2026. It was replaced by the design in
`docs/rewrite-contracts.md`; the reasons are in its §0. The analysis in `analysis-2026-11.md` shaped the rewrite.

They are kept for reference only: nothing here describes the current code. The old code itself is in git history
(the last commit with it is `e9e1d2f`), including the drawing renderer (`cat/drawings.py`, `cat/art.py`) that a
future `draw` capability can start from.
